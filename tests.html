🔺 Тренировочные тесты

10 вопросов по регламенту. Отвечайте по порядку — итоговый разбор появится автоматически.

Правильно: 0 из 10 (отвечено: 0)

Вопрос 1. Организация + реализация без отправки

Покупатель пишет: «Давайте СДЭКом, переводом на карту». Продавец: «Хорошо, номер карты [номер]». Позже покупатель: «Оплатил». Продавец: «Деньги пришли». Больше ничего не обсуждали. Какой итог по ПОДТВЕРЖДЕННЫЙ АБЬЮЗ?

Для абьюза достаточно хотя бы одного признака организации (РЕКВИЗИТЫ_ВНЕ_АВИТО = Да) и хотя бы одного признака реализации (ОПЛАТА_ВНЕ_АВИТО = Да). Отправку ждать не обязательно — оплата уже подтверждает реализацию. Применимых реализованных корнеров нет → абьюз подтверждён.

Вопрос 2. Плашка КГТ против обсуждения

Плашка КГТ у объявления = Нет. В переписке продавец прямо говорит: «Это крупногабаритный шкаф, в Авито Доставку не пройдёт». Оплата и передача вне Авито не подтверждены. Какие корнеры выбираем?

Для CC05 достаточно любого источника: либо плашка «Да», либо содержательное обсуждение крупногабаритности. Отрицательная плашка сигнал не отменяет. В «Упомянутых корнерах» → CC05. В «Реализованных» — пусто, потому что оплата и физическая передача не подтверждены.

Вопрос 3. Трек-номер — это отправка?

Продавец прислал трек-номер и написал: «Завтра отвезу в ПВЗ, скину фото». Больше про отправку в карточке ничего нет. Какую резолюцию ставим по полю ОТПРАВКА_ВНЕ_АВИТО?

Трек-номер и обещание отправить не подтверждают физическую передачу. Нужно ясное сообщение о состоявшейся передаче, приёме перевозчиком или получении покупателем.

Вопрос 4. Оплата и корнеры

Покупатель пишет: «Оплатил 5000 на номер, который вы дали». Продавец отвечает: «Деньги пришли, спасибо». В карточке других сигналов нет. Какую резолюцию ставим по ОПЛАТА_ВНЕ_АВИТО и какие корнеры выбираем?

Покупатель подтвердил перевод + продавец подтвердил поступление = факт оплаты. Но сама оплата не создаёт корнер — только если в чате был сигнал (КГТ, обмен, самовывоз и т.д.).

Вопрос 5. Ozon — какой признак?

Покупатель: «Отправьте, пожалуйста, через Ozon». Продавец: «Хорошо, пришлите адрес и телефон». Позже покупатель пишет: «Оплатил, отправляйте». Продавец: «Завтра отправлю». Какие признаки ставим?

Ozon — внешняя служба (не подключена к Авито Доставке) → ДОСТАВКА_ВНЕШНЯЯ = Да. Оплата только обещана → ОПЛАТА_ВНЕ_АВИТО = Нет.

Вопрос 6. Готовность продавца без сделки

Продавец пишет: «Могу отправить ПЭК после полной оплаты». Покупатель отвечает: «Спасибо, я подумаю». Больше сообщений нет. Какую резолюцию ставим по ГОТОВНОСТЬ_ПРОДАВЦА_ОТПРАВИТЬ_ВНЕ_АВИТО?

Продавец явно предложил отправку вне Авито. Окончательная договорённость и сделка не требуются для этого поля. При этом ДОСТАВКА_ВНЕШНЯЯ и ДОСТАВКА_НАПРЯМУЮ останутся «Нет» — договорённости-то нет.

Вопрос 7. Абьюз по одной покупке, корнер по другой

В карточке две независимые покупки. По D01 подтверждены ДОСТАВКА_ВНЕШНЯЯ и ОПЛАТА_ВНЕ_АВИТО, реализованных корнеров нет. По D02 другой товар, покупатель сам забрал его самовывозом. Какой итог по ПОДТВЕРЖДЕННЫЙ_АБЬЮЗ и какие объявления выбираем?

Абьюз подтверждён хотя бы по одной покупке — уже достаточно для «Да». CC03 (самовывоз) по D02 сохраняем в списках корнеров, но это не отменяет абьюз по D01.

Вопрос 8. Возврат после увода

Продавец передал реквизиты, покупатель перевёл, продавец подтвердил отправку. Позже покупатель пишет: «Возвращаю товар, верните деньги». Продавец переводит обратно. Какую резолюцию ставим по ПОДТВЕРЖДЕННЫЙ_АБЬЮЗ?

Увод уже был подтверждён до возврата. Последующий возврат товара и денег не отменяет первоначальный увод.

Вопрос 9. Только возврат, без покупки

В карточке единственное: покупатель пишет «Товар уже получил, хочу вернуть», продавец просит реквизиты для возврата. Других сведений о первоначальной покупке нет. Какую резолюцию ставим по ПОДТВЕРЖДЕННЫЙ_АБЬЮЗ?

Реквизиты и перевод только для возврата не подтверждают увод первоначальной покупки. Нет ни организации, ни реализации сделки вне Авито.

Вопрос 10. Несколько объявлений — один заказ

D01 — платье, покупатель пишет «Вот эту хочу заказать». D02 — туфли, покупатель пишет «И вот эти добавьте в заказ». В U2U-чате (D03) стороны договариваются отправить оба товара через внешний ПВЗ, покупатель переводит деньги за оба, продавец подтверждает. Какие объявления выбираем и какой итог по ПОДТВЕРЖДЕННЫЙ_АБЬЮЗ?

По контексту это один общий заказ из двух товаров. Договорённость и оплата относятся к обоим → абьюз подтверждён по обоим. D03 (U2U) — только контекст, не выбирается.
