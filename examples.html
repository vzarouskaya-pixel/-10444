    5.1. Организация сделки

    ДОСТАВКА_ВНЕШНЯЯ

    Согласовали отправку через Ozon Пример

    Покупатель: «Если можно, отправкой озон пожалуйста)»

    Продавец: «Да, хорошо. Пришлите адрес озон и номер телефона»

    ДОСТАВКА_ВНЕШНЯЯ = «Да»: есть явная договоренность об отправке через внешнюю службу доставки, не подключенную к Авито Доставке.

    Согласовали отправку «Энергией» Пример

    Покупатель: «ТК КИТ сможете отправить?»

    Продавец: «Энергией удобно вам будет?»

    Покупатель: «Хорошо, жду отправки.»

    Продавец: «Ок, завтра отправлю.»

    ДОСТАВКА_ВНЕШНЯЯ = «Да»: покупатель согласился на предложенную внешнюю службу. Одного упоминания названия службы было бы недостаточно.

    ДОСТАВКА_НАПРЯМУЮ

    Предложение отправить СДЭКом по предоплате Пример

    Покупатель: «Сдзк отправляете ?»

    Продавец: «Конечно»

    Продавец: «Но я отправляю после полной оплаты... адрес вашего сдэка... а вы мне переводите»

    ДОСТАВКА_НАПРЯМУЮ = «Да», если в материалах явно видно согласие покупателя на отправку СДЭКом с переводом продавцу вне оформления Авито Доставки. Здесь показано предложение продавца, но согласие покупателя на эти условия не приведено. По одному показанному фрагменту договоренность не подтверждена; если других подтверждений нет, ставьте «Нет».

    СДЭК с переводом продавцу Пример

    Покупатель: «Доставка по предоплате СДЭКом допустима?»

    Продавец: «Допустимо.»

    Покупатель: «В качестве способа оплаты будет перевод по номеру телефона, да?»

    Продавец: «Да.»

    ДОСТАВКА_НАПРЯМУЮ = «Да»: отправку СДЭКом согласовали с оплатой продавцу переводом, вне оформления Авито Доставки.

    Обсуждение службы доставки само по себе не означает ДОСТАВКА_НАПРЯМУЮ Контрпример

    Продавец: «Или СДЭК пункт рядом с домом у меня»

    Продавец: «А если попробовать 5post?»

    Если других подтверждений договоренности нет, ДОСТАВКА_НАПРЯМУЮ = «Нет»: здесь обсуждаются варианты доставки, но еще нет достаточной договоренности об отправке напрямую вне Авито.

    РЕКВИЗИТЫ_ВНЕ_АВИТО

    Номер карты для оплаты товара Пример

    Продавец: «[номер карты] <PERSON_NAME-#0> Сбербанк»

    Продавец: «Чек после оплаты»

    РЕКВИЗИТЫ_ВНЕ_АВИТО = «Да»: продавец отправляет реквизиты для оплаты не через Авито.

    Платежные реквизиты прозвучали в звонке Пример

    В звонке согласуют перевод за товар. Номер продиктован голосом, а не написан в чате.

    Покупатель: «Давайте, я пишу.»

    Продавец: «Записывайте: [телефон для перевода]. На Т-Банк.»

    Покупатель: «Т-Банк, все, сейчас сделаю.»

    РЕКВИЗИТЫ_ВНЕ_АВИТО = «Да»: есть номер и его платежное назначение. Реквизиты из звонка учитываются так же, как из переписки.

    Телефон только для доставки Пример

    Продавец: «Введите, пожалуйста, свой номер телефона, нужно для курьера.»

    Покупатель: «[контактный телефон].»

    Этот фрагмент не дает РЕКВИЗИТЫ_ВНЕ_АВИТО = «Да»: телефон нужен для доставки, платежное назначение не показано. Если в других материалах есть платежные реквизиты, их нужно учесть отдельно.

    Реквизиты сами по себе еще не означают подтвержденный увод сделки Контрпример

    Продавец: «Сбербанк: 2202 ...»

    ...

    Продавец: «Давайте все-таки через Авито»

    Продавец: «Заказ оформили, отправка товара в течении 3-х дней с момента оформления заказа (в установленный срок Авито)»

    По приведенным данным РЕКВИЗИТЫ_ВНЕ_АВИТО = «Да», ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Нет»: отправка реквизитов сама по себе является признаком, но далее из переписки видно, что сделка оформлена через Авито.

    ГОТОВНОСТЬ_ПРОДАВЦА_ОТПРАВИТЬ_ВНЕ_АВИТО

    Продавец готов отправить вне Авито, покупатель выбирает другое Пример

    Продавец: «Могу отправить транспортной ПЭК после полной оплаты.»

    Покупатель: «Давайте все-таки я через Авито Доставку куплю.»

    Готовность продавца = «Да»: он явно предложил отправку вне Авито. Договоренность не достигнута: оба признака доставки = «Нет». Предложение не доказывает оплату или отправку.
    5.2. Оплата и отправка

    ОПЛАТА_ВНЕ_АВИТО

    Короткие реплики без понятного платежного контекста Контрпример

    Покупатель: «Готово»

    Продавец: «Вижу, <PERSON_NAME-#1> ?»

    Покупатель: «Да»

    По одному показанному фрагменту недостаточно данных для ОПЛАТА_ВНЕ_АВИТО = «Да»: неясно, к какому действию относятся «Готово» и «Вижу». Нужно подтверждение, что речь о состоявшемся переводе вне Авито за эту покупку. Подойдет сообщение покупателя и/или подтверждение продавца с понятным платежным контекстом. Если такого подтверждения нет, ставьте «Нет».

    Перевод подтвержден обеими сторонами Пример

    Покупатель: «Надо еще вам оплатить.»

    Покупатель: «Перевел вам.»

    Продавец: «Деньги пришли.»

    ОПЛАТА_ВНЕ_АВИТО = «Да»: покупатель сообщил о переводе, продавец подтвердил поступление. В этих репликах способ передачи товара не указан. Оба списка СС заполняйте по остальным материалам карточки: не добавляйте корнер только на основании состоявшейся оплаты.

    Обещание перевести деньги Контрпример

    Покупатель: «Как переведу, напишу, сколько и от кого.»

    Продавец: «Хорошо.»

    Обещание не подтверждает платеж. Если других подтверждений оплаты в карточке нет, ОПЛАТА_ВНЕ_АВИТО = «Нет».

    Оплата через Авито не считается оплатой вне Авито Контрпример

    Покупатель: «Вот оплата»

    ... в подтверждении оплаты видно, что платеж относится к Avito Dostavka

    Для показанного платежа ОПЛАТА_ВНЕ_АВИТО = «Нет»: сама оплата относится к оплате через Авито, а не к оплате вне Авито.

    ОТПРАВКА_ВНЕ_АВИТО

    Посылка ожидает на почте Контрпример

    Продавец: «Сегодня постараюсь отправить и отпишу»

    Продавец: «[трек-номер] трек номер для отслеживания покупки»

    Продавец: «Здравствуйте, покупка ожидает на почте»

    Сообщение «покупка ожидает на почте» подтверждает движение физического товара, но не показывает, оформлена ли отправка вне Авито. По одному показанному фрагменту недостаточно данных для ОТПРАВКА_ВНЕ_АВИТО = «Да». Нужна понятная связь этой посылки с отправкой вне Авито; если ее нет в материалах карточки, ставьте «Нет».

    Самовывоз и последующее использование товара Пример

    Покупатель приезжает за компьютером. Позже он обсуждает с продавцом его работу дома.

    Покупатель: «Скоро подойду.»

    Продавец: «Ок.»

    Покупатель: «Когда домой пришел, подключил. В игру заходил.»

    ОТПРАВКА_ВНЕ_АВИТО = «Да»: получение физического товара подтверждено его использованием. В обоих списках СС выбираем СС03: самовывоз реализован. Абьюз по этой покупке = «Нет». Оба признака доставки = «Нет».

    Оплата и оформление еще не подтверждают отправку Контрпример

    Стороны оформляют внешнюю доставку через Ozon.

    Покупатель: «Пришло?»

    Продавец: «Да, только еще надо доплатить.»

    Продавец: «Посмотрите, появилось ли у вас что-то во вкладке Ozon Доставка.»

    Продавец: «Если да, то завтра-послезавтра все отправлю.»

    Оплата и оформление доставки не заменяют факт передачи товара. Здесь отправка только обещана. Без другого подтверждения физической передачи, движения или получения ОТПРАВКА_ВНЕ_АВИТО = «Нет».
    5.3. Корнеры и итоговое решение

    Задаток за бронь товара не считается нарушением Контрпример

    Покупатель: «Можно забронировать до 11.02?»

    Продавец: «Если задаток внесете то да»

    Покупатель: «Куда переводить?»

    Продавец: «Фотик за вами»

    В «Упомянутых корнерах» — СС12. В приведенных репликах нет подтверждения перевода или физической передачи, поэтому «Реализованные корнеры» пусты и абьюз = «Нет». Если отдельно подтвердится оплата брони вне Авито, во втором списке тоже выбираем СС12; эта покупка исключается из абьюза.

    Самовывоз без ответа продавца Пример

    Покупатель спрашивает, когда можно посмотреть и забрать товар; продавец еще не ответил.

    В «Упомянутых корнерах» выбираем СС03, а «Реализованные корнеры» оставляем пустыми. В этом фрагменте оба признака доставки, оплата и физическая отправка = «Нет». Реализация не подтверждена: абьюз = «Нет».

    Такси и факт передачи проверяются отдельно Пример

    Покупатель: «Сможете вынести, если просто такси закажу?»

    Продавец: «Если в ближайшее время, то да.»

    Продавец: «Передали.»

    В «Упомянутых корнерах» выбираем СС01 по обсуждению такси. Реплика «Передали» подтверждает физическую передачу по этому сценарию: во втором списке тоже СС01, ОТПРАВКА_ВНЕ_АВИТО = «Да». Абьюз по этой покупке = «Нет».

    У одной покупки могут быть несколько реализованных корнеров Пример

    Плашка КГТ у объявления = «Да». Покупатель вызывает машину для передачи товара.

    Продавец: «Машина назначена?»

    Покупатель: «Напишите, пожалуйста, как отдадите.»

    Продавец: «Отдали.»

    В обоих списках выбираем СС05 и СС01. Для СС05 достаточно положительной плашки того же товара; обсуждать крупногабаритность дополнительно не нужно. Физическая передача этого товара по обсуждавшемуся сценарию подтверждена. Абьюз по этой покупке = «Нет». Сохраняйте все подходящие коды.

    Плашка КГТ — «Нет», но крупногабаритность обсуждается Пример

    В карточке плашка КГТ = «Нет». В разговоре о том же товаре участник прямо говорит, что это крупногабаритный шкаф. Оплата и физическая передача вне Авито не подтверждены.

    В «Упомянутых корнерах» выберите СС05: явного обсуждения достаточно, отрицательная плашка его не отменяет. «Реализованные корнеры» пусты. ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Нет»: реализация не подтверждена.

    Плашка КГТ — «Да» без обсуждения крупногабаритности Пример

    У товара плашка КГТ = «Да». Крупногабаритность в переписке не обсуждают. Для покупки этого товара согласована отправка в ПВЗ OZON вне Авито и подтверждена оплата вне Авито; других оснований для корнера нет.

    В обоих списках выберите СС05: положительной плашки достаточно для сигнала, а оплата подтверждает реализацию покупки этого товара. ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Нет».

    Обсуждали курьера, выбрали доставку в ПВЗ OZON Пример

    Сначала стороны обсуждали передачу курьеру. Затем для этой же покупки согласовали отправку в ПВЗ OZON вне Авито и подтвердили перевод денег за товар вне Авито. Плашка КГТ — «Нет»; других оснований для корнера нет.

    В «Упомянутых корнерах» — СС01; «Реализованные корнеры» пусты: покупку реализовали по другому сценарию. ДОСТАВКА_ВНЕШНЯЯ и ОПЛАТА_ВНЕ_АВИТО = «Да», ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да». Достаточно подтвержденной оплаты; отправки ждать не нужно.

    Обсуждали обмен, затем состоялась продажа Пример

    Покупатель предложил обмен, продавец отказался. После этого стороны согласовали обычную продажу с доставкой вне Авито и подтвердили оплату вне Авито. Обмен не реализован; других оснований для корнера нет.

    В «Упомянутых корнерах» — СС10; «Реализованные корнеры» пусты: подтверждена обычная продажа, а не обмен. При подтвержденных организации и оплате вне Авито ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да».

    Занижение цены в Авито с доплатой на карту Пример

    Покупатель: «Может лучше через авито?»

    Продавец: «Ок, остаток сможете прислать на карту? Чтобы не платить комиссию»

    Продавец: «Цену укажу 10р для оформления»

    Это пример схемы абьюза. Если в полной переписке переданы реквизиты, отметьте РЕКВИЗИТЫ_ВНЕ_АВИТО = Да; если подтверждён перевод остатка — ОПЛАТА_ВНЕ_АВИТО = Да. Итог определяйте по общему правилу из раздела 2.

    Низкая цена сама по себе не означает нарушение Контрпример

    В объявлении или в оформлении указана низкая цена, но в переписке нет явной договоренности о переводе остатка суммы вне Авито.

    По приведенным данным ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Нет»: само по себе занижение цены без явной договоренности о доплате вне Авито еще не подтверждает увод сделки.

    Только возврат Контрпример

    Покупатель: «Товар уже получил, но хочу вернуть».

    Продавец просит реквизиты для возврата денег. Позже продавец пишет: «Возврат перевёл».

    Других сведений о том, как была проведена первоначальная покупка, в карточке нет.

    Реквизиты и перевод относятся только к возврату средств. Они не подтверждают увод первоначальной покупки. ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Нет».

    Возврат после подтвержденного увода Пример

    До получения товара продавец передал реквизиты, покупатель подтвердил перевод, а продавец подтвердил отправку товара вне Авито. Позже покупатель сообщает, что возвращает товар, а продавец переводит деньги обратно.

    Первоначальная покупка вне Авито уже подтверждена. Последующий возврат товара и денег не отменяет увод. ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да».
    5.4. Несколько объявлений и покупок

    Продолжение сделки в другом чате Пример

    D01, объявление о лампе: стороны договариваются отправить лампу через внешний ПВЗ.
    D02, другое объявление: покупатель прямо пишет, что перешел сюда из первого чата, перевёл сумму за лампу; продавец подтверждает поступление.

    Это одна сделка по лампе. ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да»; выбрать объявление о лампе.

    Несвязанные покупки не складываются в один увод Контрпример

    D01: согласована внешняя доставка лампы, но оплаты или отправки ещё нет.
    D02: подтверждена оплата обуви, но нет договорённости проводить сделку с обувью вне Авито.

    Это разные покупки, и переписка не связывает их в один заказ. ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Нет»; список объявлений оставить пустым. При этом отметить фактически встретившиеся признаки: ДОСТАВКА_ВНЕШНЯЯ = «Да» и ОПЛАТА_ВНЕ_АВИТО = «Да». Их нельзя объединить для итогового решения, потому что они относятся к разным покупкам.

    Подтвержденный увод по нескольким товарам Пример

    D01: по лампе есть договоренность о внешней доставке и подтверждён перевод вне Авито.
    D02: по обуви отдельно есть договоренность о прямой доставке и подтверждена отправка.

    По каждой из двух покупок отдельно выполнены три условия. ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да»; выбрать D01 и D02.

    Один общий заказ из нескольких объявлений Пример

    D01, объявление о платье: покупатель пишет «Вот эту хочу заказать».
    D02, объявление о туфлях: покупатель пишет «И вот эти добавьте в заказ».
    D03, чат без объявления: стороны договариваются отправить оба товара через внешний ПВЗ; покупатель сообщает, что перевел деньги за оба товара, продавец подтверждает получение.

    По контексту это один заказ из двух товаров, а договоренность и оплата относятся к обоим. Отметить ДОСТАВКА_ВНЕШНЯЯ = «Да» и ОПЛАТА_ВНЕ_АВИТО = «Да». ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да»; выбрать D01 и D02. D03 используется как контекст и не выбирается.

    КГТ другого товара не переносится Пример

    D01: по обычному товару доказаны договоренность и оплата вне Авито.
    D02: другой товар имеет положительный КГТ-флаг.

    ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да»: в «Упомянутых корнерах» выбираем СС05 по положительной плашке D02. По D02 нет подтверждения реализации, поэтому «Реализованные корнеры» пусты. Сигнал по D02 не дает исключения для независимой покупки D01. По D01 подтвержден абьюз; выбрать D01.

    Для итога достаточно оплаты или отправки Пример

    Часы и ключницу покупают одним заказом. Продавец передал телефон для оплаты. Плашки КГТ = «Нет»; подходящих корнеров в материалах этой покупки нет.

    Покупатель: «Можете через Ozon отправить мне вместе с часами?»

    Продавец: «Напишите, куда выслать, на какой Ozon.»

    Покупатель: «Отправила. В СМС написала, чтобы узнали, от кого перевод.»

    Продавец: «Хорошо, пришли.»

    ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да»: есть организация внешней доставки и подтвержденная оплата, оба списка СС пусты. Для реализации достаточно оплаты, одновременно подтверждать отправку не обязательно. В списке объявлений выбираем часы и ключницу, которые входят в этот заказ.

    Одна покупка с корнером, другая с абьюзом Пример

    В карточке две независимые покупки. По D01 согласована внешняя доставка и подтверждена оплата вне Авито, реализованных корнеров нет. По D02 другой товар уже забрали самовывозом.

    В обоих общих списках выберите СС03: по D02 состоялся самовывоз. По D01 подтвержден абьюз без реализованных корнеров. В ответе карточки ПОДТВЕРЖДЕННЫЙ АБЬЮЗ = «Да». В отдельном поле объявлений с уводом выберите только D01. Основные признаки и готовность продавца заполняйте по покупке D01.
    5.5. Примеры по изображениям

    Как трактовать изображения. Изображение оценивается только вместе с контекстом переписки, а не изолированно.

    • если изображение содержит реквизиты для перевода, это может быть признаком РЕКВИЗИТЫ_ВНЕ_АВИТО;
    • если изображение содержит подтверждение успешного перевода, это может быть признаком ОПЛАТА_ВНЕ_АВИТО;
    • если изображение подтверждает прием физического товара перевозчиком, его движение или получение, это может быть признаком ОТПРАВКА_ВНЕ_АВИТО;
    • один трек-номер, созданная накладная или статус «Оформлено» сами по себе недостаточны.

    РЕКВИЗИТЫ_ВНЕ_АВИТО

    QR-код для оплаты на изображении Пример

    Продавец: «Qr действует 20 минут»

    QR-код для оплаты на изображении
    РЕКВИЗИТЫ_ВНЕ_АВИТО = «Да»: продавец передает реквизиты для оплаты вне Авито в виде изображения, а не текстом.

    ОПЛАТА_ВНЕ_АВИТО

    Квитанция со скрытым статусом платежа Контрпример

    Покупатель отправляет квитанцию перевода после получения реквизитов.

    Квитанция со скрытым статусом платежа
    На этом скриншоте значение статуса скрыто. По одному показанному скриншоту нельзя подтвердить успешность платежа. Для ОПЛАТА_ВНЕ_АВИТО = «Да» нужны читаемое подтверждение успешной операции либо сообщение покупателя и/или подтверждение продавца о состоявшемся платеже. Также должно быть понятно, что платеж проведен вне Авито и относится к этой покупке. Если нужных подтверждений нет, ставьте «Нет».

    Скриншот оплаты через Авито Контрпример

    Покупатель: «Вот оплата»

    Скриншот оплаты через Avito Dostavka
    Если платеж через Avito Dostavka, для него ОПЛАТА_ВНЕ_АВИТО = «Нет»: сам по себе банковский скриншот еще не означает обход Авито; важно, к какой именно схеме относится платеж. Если из изображения видно, что это Avito Dostavka, такой скриншот не подтверждает оплату вне Авито.

    ОТПРАВКА_ВНЕ_АВИТО

    Оформление еще не подтверждает отправку Контрпример

    Продавец: «[трек-номер] трек номер для отслеживания покупки»

    Скриншот доставки — активен только статус «Оформлено»
    Если других подтверждений физической отправки вне Авито нет, ОТПРАВКА_ВНЕ_АВИТО = «Нет»: на скриншоте активен только статус «Оформлено». Само оформление и переданный трек-номер еще не подтверждают физическую отправку. Для ОТПРАВКА_ВНЕ_АВИТО = «Да» нужно другое ясное подтверждение приема, передачи, движения или получения товара вне Авито.
